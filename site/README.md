# Sling website

Plain HTML and CSS. No build step and no dependencies.

- Preview: open `index.html` in a browser.
- Publish: drag this `site` folder onto Netlify Drop (app.netlify.com/drop), or point Netlify, Vercel, Cloudflare Pages or GitHub Pages at this folder.
- Styles: `css/tokens.css` (brand tokens, copied from `design-system/`), `css/components.css` (brand components) and `css/site.css` (layout).
